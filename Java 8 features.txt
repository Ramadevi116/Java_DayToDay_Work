Functional Interface and Lambda Expression:


Lambda Expression: No method name
		   No return type
		   

example:
=======

package Java8;


interface FunctionalInterface {
	public void run();                   //Single abstract method
}

package Java8;

public class FunctionalInterfaceImplementation  {
	public static void main(String[] args) {	
	FunctionalInterface fi=()->{System.out.println("Hello");};  // Lambda expression
	fi.run();
	}
}


package Java8;

public class FunctionalInterfaceImplementation  {
	public static void main(String[] args) {	
		
	print(()->{System.out.println("Hii");});
	
	}
	private static void print(FunctionalInterface f) {
		f.run();
	}
}

Functional Interface:
====================

Only one abstract method
More than one default and static methods
@FunctionalInterface annotation
To implement functionalInterface methods we use lambda expression.

Predefined Functional interfaces:
=================================

Function<T,R> -> R apply(T t);
Consumer<T> -> void accept(T t);
Supplier<T> -> R get();
Predicate<T,T> -> boolean test(T t);
BiPredicate
BiConsumer
BiFunction
UnaryOperator
BinaryOperator


Ex: Runnable - run()
    Callable - call()
    Comparable - compareTO()



Function<T,R>: Accept one argument and provide the result.
=============
R apply(T t) -> Function method to accept Argument and return the value.

Example:
=======

package Java8;

import java.util.function.Function;

class FunctionalInterface implements Function<String, Integer>{
	
	public Integer apply(String s) {
		return s.length();
	}
	
	public static void main(String[] args) {
		Function<String, Integer> function=new FunctionalInterface();
		System.out.println(function.apply("Java"));
	}
}

Stream Api:
===========
->No need to modify the original data.
->Convert collections like list, set etc to stream and do actions like filter, mapping etc without any modification of original data.
->flow: Source-filter-sort-map-collect/reduce.

sort and print exp: 
==================
List<String> s=Arrays.asList("r","a","c");
		s.stream().sorted().forEach(e->System.out.println(e));
